# mathematics-competition

当前仓库主要包含三类内容：

- CMC（全国大学生数学竞赛）历年真题、汇编、解析及相关竞赛资料；
- 数学分析、高等代数等课程的原始参考 PDF；
- 已工程化整理的 LaTeX 讲义，其中目前完成度最高的是 `数学分析培优/`。

## 数学分析培优

`数学分析培优/` 已完成 13 章的 LaTeX 工程化整理，并迁移到定制的 ElegantBook 文档类。

当前采用“单源正文 + 双输出”结构：

```text
同一份章节内容
├─ 普通版：完整理论正文 + 例题 + 书写留白
└─ 答案版：完整理论正文 + 例题 + 解答
```

每章使用三文件结构：

```text
第X章_章名/
├─ 第X章_章名_内容.tex
├─ 第X章_章名.tex
└─ 第X章_章名(答案版).tex
```

其中 `_内容.tex` 是唯一真正维护数学正文的文件，普通版和答案版入口均读取这一份内容，避免题面、正文和答案重复维护。

## 编译

推荐环境：

```text
Windows
TeX Live
VS Code
LaTeX Workshop
XeLaTeX
latexmk
```

进入：

```text
数学分析培优/
```

编译普通版：

```powershell
latexmk -xelatex "数学分析培优讲义.tex"
```

编译答案版：

```powershell
latexmk -xelatex "数学分析培优讲义(答案版).tex"
```

清理辅助文件：

```powershell
latexmk -C
```

每章的普通版和答案版入口也支持独立编译。

## LaTeX 结构

    通用排版能力、页面布局、定理环境、数学宏包、

    本讲义自己的页眉、水印文字、标题页、

    真正的数学正文、例题与 solution
