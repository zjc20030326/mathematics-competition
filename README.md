当前仓库主要包含三类内容：

- CMC（全国大学生数学竞赛）历年真题、汇编、解析及相关竞赛资料；
- 数学分析、高等代数等课程的原始参考 PDF；

## 数学分析培优

`数学分析培优/` 已完成 13 章的 LaTeX 工程化整理，并迁移到定制的 ElegantBook 文档类。

当前采用“单源正文 + 双输出”结构：

```text
同一份章节内容
├─ 普通版：完整理论正文 + 例题 + 书写留白
└─ 答案版：完整理论正文 + 例题 + 解答
```

每章使用三文件结构：

```text
第X章_章名/
├─ 第X章_章名_内容.tex
├─ 第X章_章名.tex
└─ 第X章_章名(答案版).tex
```

其中 `_内容.tex` 是唯一真正维护数学正文的文件，普通版和答案版入口均读取这一份内容，避免题面、正文和答案重复维护。

其中第十章《张量积与外积》是原讲义的选学章节，包含张量积的构造与万有性、维数与基、对偶与自然同构、Kronecker 积，以及外积与行列式的联系等内容。

### 例题规模

当前共整理 **511 道例题**，每道例题对应一个 `solution`，普通版与答案版均由同一份章节内容源码生成。

### 难度与选学标记

难度只使用两档五角星，写在定理、命题或例题的可选参数中：

```text
\markstar         ★
\marktwostar      ★★
```

不使用三角形标记（`\marktriangle`、`\markstartriangle`）。

第十章《张量积与外积》是原讲义的选学章节，按数学分析培优标记选学的同一写法，在标题末尾加 ASCII 星号：

```latex
\chapter{张量积与外积 *}
```

方法分类使用 `\subsection`，不引入数学分析培优的 `\methodsection` 机制。

## ElegantBook 工程结构

两个讲义项目都采用定制 ElegantBook，并且共用同一份 `elegantbook.cls` 与 `preamble.tex`——两份文件在各讲义目录下逐字节相同。

职责划分为：

```text
elegantbook.cls
    通用排版能力、页面布局、定理环境、数学宏包、
    watermark 开关、answer/noanswer 开关等

preamble.tex
    页眉、水印文字、标题页、例题编号、
    留白、methodsection、数学算子等

第X章_章名_内容.tex
    真正的数学正文、例题与 solution
```

因为共享同一套文件，两本讲义的页眉、水印、标题页样式、例题编号和数学算子是统一的：

```text
页眉右与水印    欧拉的小迷弟
封面署名        \author{欧拉的小迷弟}、\date{\today}
水印开关        \ifmathanalysiswatermark（主文件定义，preamble 读取）
数学算子        \Tr \tr \rank \diag \Ree \Imm \Ker \Span
```

各本之间互相独立的只有书名、章节列表、正文学术内容与问题记录。

改动 `elegantbook.cls`、`preamble.tex` 或任一主文件后，两本需要同步修改；是否编译验证按 AGENTS.md §15 执行。

不要维护普通版和答案版两套数学正文。

## 编译

推荐环境：

```text
Windows
TeX Live
VS Code
LaTeX Workshop
XeLaTeX
latexmk
```

数学分析：

```powershell
cd "数学分析培优"
latexmk -xelatex "数学分析培优讲义.tex"
latexmk -xelatex "数学分析培优讲义(答案版).tex"
```

```powershell
cd "高等代数培优"
latexmk -xelatex "高等代数培优讲义.tex"
latexmk -xelatex "高等代数培优讲义(答案版).tex"
```

## 原始资料

`source/` 中保存数学分析和高等代数相关的原始打印版 PDF，主要用于：

- 内容录入；
- 公式核对；
- 疑问题面校勘；
- 后续其他子项目整理。

规则：

- 不直接修改原始 PDF；
- 源码与 PDF 疑似不一致时，先对照 PDF；
- 不把模型推断静默当作原题内容；
- 原题确有疑义时，应在正文中明确说明，并同步记录到对应讲义的问题记录文件。

`CMC历年真题/` 则主要保存全国大学生数学竞赛及相关竞赛资料，目前以资料归档与查阅为主。
