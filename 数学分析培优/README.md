# 数学分析培优讲义 LaTeX 工程

- 总书编译：在项目根目录编译 `数学分析培优讲义.tex`。
- 答案版编译：在项目根目录编译 `数学分析培优讲义(答案版).tex`。
- 章节目录：每章单独存放在 `章节/第X章_章名/` 中，章文件名与文件夹名一致。
- 单章编译：直接打开 `章节/第X章_章名/第X章_章名.tex` 编译；每章通过 `subfiles` 继承总书导言区，并预设正确章号。
- 答案章节：每章目录内的 `第X章_章名(答案版).tex` 只保留标题层级、例题与紧随其后的解答，不复制定理和普通正文；可直接单章编译。
- 分页规则：`\chapter` 自身换页；新的 `section` 仍在标题前分页；`subsection` 和 `methodsection` 均不分页。
- 例题留白：原讲义的例题后统一通过 `\exampleblank` 留出书写空间；答案版不使用 `\exampleblank`。
